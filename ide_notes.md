# Git в VS Code — заметки

## Что попробовал через Source Control
- Просмотр изменённых файлов (панель Source Control, значок ветки)
- Коммит через UI: ввёл сообщение → Ctrl+Enter
- Push через кнопку "Sync Changes"
- Создание ветки через "Create Branch" в статус-баре
- Переключение веток через статус-бар (внизу слева)
- Просмотр diff: клик по файлу в Source Control

## Отличия от терминала
- В терминале: `git add`, `git commit -m`, `git push` — всё вручную
- В IDE: те же действия в 1-2 клика, но скрыты детали
- Плюс IDE: визуальный diff, встроенный merge-конфликт редактор
- Минус IDE: не всё доступно (rebase -i, cherry-pick — сложнее)
- Вывод: на сервере будет только терминал → CLI обязателен
